3. Modeling¶

  • This notebook includes training and evaluation of six tree-based classification models (Random Forest, XGBoost, and LightGBM, each in two training window configurations), together with a soft voting ensemble that averages predicted probabilities across all six models.
  • All models use a walk-forward validation scheme: the training window rolls forward in 21-day steps, with RandomizedSearchCV and nested TimeSeriesSplit inner cross-validation re-run at each step.
  • A random walk benchmark (yesterday's direction as the prediction) is included as a naive baseline.
  • Feature importance is computed using SHAP values.
  • SHAP values are normalized per model so that each model's attributions sum to 1, making relative feature importance comparable across different models.
  • Predictions are saved to predictions.csv and are used in the backtest.

Machine learning models¶

  • All three model families — Random Forest, XGBoost, and LightGBM — belong to the class of tree-based ensemble methods. They are well-suited for this task because they handle non-linear relationships, feature interactions, and noisy data without requiring normalization or distributional assumptions about the input features.
  • Random Forest builds a large number of decision trees independently using bootstrap sampling and random feature subsets at each split. Final predictions are averaged across all trees, which reduces variance and prevents overfitting.
  • XGBoost uses gradient boosting: trees are built sequentially, where each new tree corrects the residual errors of the previous ensemble.
  • LightGBM follows the same gradient boosting principle as XGBoost but uses leaf-wise tree growth instead of depth-wise. This makes it significantly faster on high-dimensional data while achieving comparable predictive accuracy.

Walk-forward validation scheme¶

  • Standard cross-validation randomly splits data into folds, which causes data leakage in time series — future observations end up in the training set.
  • Walk-forward validation avoids this by strictly respecting the chronological order of data.
  • The procedure works as follows: A fixed-size training window is placed at the start of the dataset. The model is trained on this window and used to predict the next 21 trading days (one month). The window then shifts forward by 21 days and the process repeats — each step trains a fresh model on the most recent data and predicts the next unseen period.
  • Hyperparameter tuning is performed inside each training window using a nested TimeSeriesSplit cross-validation with RandomizedSearchCV. This means the best hyperparameters are re-selected at every step.
  • Two window sizes are tested for each model family: 252 trading days (~1 year) and 504 trading days (~2 years).
  • The scheme is illustrated in the figure below.

def evaluate(model_name, y_true, y_pred, y_prob, eval):
    print(confusion_matrix(y_true, y_pred))
    tn, fp, fn, tp = confusion_matrix(y_true, y_pred).ravel()
    row = pd.DataFrame([{
        "Accuracy":    round(accuracy_score(y_true, y_pred), 3),
        "AUC":         round(roc_auc_score(y_true, y_prob), 3),
        "Sensitivity": round(tp / (tp + fn), 3),
        "Specificity": round(tn / (tn + fp), 3),
    }], index=[model_name])
    return pd.concat([eval, row])

def walk_forward_rf(X, y, train_window, cv_train_window, val_window, step, param_distributions, n_iter):
    
    results = []
    shap_rows = []
    train_start = 0
    train_end = train_window

    n_splits = (train_window - cv_train_window) // val_window
    inner_cv = TimeSeriesSplit(n_splits=n_splits, max_train_size=cv_train_window, test_size=val_window)

    while train_end < len(X):
        X_train = X.iloc[train_start:train_end]
        y_train = y.iloc[train_start:train_end]

        search = RandomizedSearchCV(
            RandomForestClassifier(random_state=1, class_weight="balanced"),
            param_distributions,
            n_iter=n_iter,
            cv=inner_cv,
            scoring="balanced_accuracy",
            random_state=1,
            n_jobs=-1,
        )
        search.fit(X_train, y_train)
        print(f"{X_train.index[-1].date()} | best params: {search.best_params_}")

        pred_end = min(train_end + step, len(X))
        X_pred = X.iloc[train_end:pred_end]
        y_true = y.iloc[train_end:pred_end]
        preds = search.best_estimator_.predict(X_pred)
        probs = search.best_estimator_.predict_proba(X_pred)[:, 1]

        for date, tv, pv, pb in zip(X_pred.index, y_true, preds, probs):
            results.append({"date": date, "y_true": tv, "y_pred": pv, "prob_up": pb})

        explainer = shap.TreeExplainer(search.best_estimator_)
        shap_vals = explainer.shap_values(X_pred)
        sv = shap_vals[:, :, 1] if hasattr(shap_vals, 'ndim') and shap_vals.ndim == 3 else shap_vals[1]
        shap_rows.append(pd.DataFrame(sv, index=X_pred.index, columns=X_pred.columns))

        train_start += step
        train_end += step

    results_df = pd.DataFrame(results).set_index("date")
    shap_df = pd.concat(shap_rows)
    return results_df, shap_df

Walk-Forward Evaluation function¶

def walk_forward_xgb(X, y, train_window, cv_train_window, val_window, step, param_distributions, n_iter):

    results = []
    shap_rows = []
    train_start = 0
    train_end = train_window

    n_splits = (train_window - cv_train_window) // val_window
    inner_cv = TimeSeriesSplit(n_splits=n_splits, max_train_size=cv_train_window, test_size=val_window)

    while train_end < len(X):
        X_train = X.iloc[train_start:train_end]
        y_train = y.iloc[train_start:train_end]

        neg = (y_train == 0).sum()
        pos = (y_train == 1).sum()
        spw = neg / pos

        search = RandomizedSearchCV(
            XGBClassifier(random_state=1, scale_pos_weight=spw, eval_metric="logloss"),
            param_distributions,
            n_iter=n_iter,
            cv=inner_cv,
            scoring="balanced_accuracy",
            random_state=1,
            n_jobs=-1,
        )
        search.fit(X_train, y_train)
        print(f"{X_train.index[-1].date()} | best params: {search.best_params_}")

        pred_end = min(train_end + step, len(X))
        X_pred = X.iloc[train_end:pred_end]
        y_true = y.iloc[train_end:pred_end]
        preds = search.best_estimator_.predict(X_pred)
        probs = search.best_estimator_.predict_proba(X_pred)[:, 1]

        for date, tv, pv, pb in zip(X_pred.index, y_true, preds, probs):
            results.append({"date": date, "y_true": tv, "y_pred": pv, "prob_up": pb})

        explainer = shap.TreeExplainer(search.best_estimator_)
        shap_vals = explainer.shap_values(X_pred)
        shap_rows.append(pd.DataFrame(shap_vals, index=X_pred.index, columns=X_pred.columns))

        train_start += step
        train_end += step

    results_df = pd.DataFrame(results).set_index("date")
    shap_df = pd.concat(shap_rows)
    return results_df, shap_df

Summary¶

Model performance¶

  • All models achieve accuracy slightly above the random walk baseline (0.505), with the ensemble model reaching the highest accuracy of 0.528.
  • Models predict UP days more reliably than DOWN days — sensitivity consistently exceeds specificity across all models, likely reflecting the overall upward trend of SPY in the test period.
  • The small gains over the baseline suggest that the features carry limited predictive signal for daily direction on their own.
  • Whether these gains translate into profitable trading strategies is evaluated in the backtest.

Feature importance¶

  • The five most important features across all models are skew_log_change_lag1, svi_ema_slow_std, svi_ema_fast_std, svi_delta_ema_fast, and skew_log_change_ema_slow.
  • Raw level values (e.g. how high SKEW is today) rank lower than their derived counterparts, indicating that the rate of change and its dispersion carry more predictive signal than absolute levels.
